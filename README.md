# The Predictive Universe

The Predictive Universe (PU) explores how quantum behavior, spacetime, and thermodynamics may arise from finite predictive systems constrained by self-reference and resources. It is part of Universe 00110000, an artistic world-building project.

Download and extract this repository, keep its folders together, and open [index.html](index.html) in any modern browser. Read the paper in the **Paper** tab or explore its concepts in **Visualizations**. Both work offline with no dependencies.

Use **Contents** or **Search** to navigate the paper. In the visualizations, select a scene and click **Explain** to read about it.

The manuscript and appendices are also available in [docs/paper](docs/paper/). The [Pure S companion paper](docs/paper/related/pure_s_universality/output/pdf/pure_s_universality.pdf) opens as a separate PDF.

The Pure S companion uses external software for optional verification and PDF rebuilding:

- **[Verification](docs/paper/related/pure_s_universality/VERIFICATION.md):** Python, pypdf, Git, Lean 4 (including Lake, `leanchecker`, and bundled Clang), and `lean4lean` with Batteries.
- **[PDF rebuilding](docs/paper/related/pure_s_universality/PUBLICATION.md):** Pandoc, TeX Live/XeLaTeX, Latin Modern fonts, and the `tagpdf`, `xurl`, `needspace`, and `upquote` packages.
- **[Optional container setup](docs/paper/related/pure_s_universality/Dockerfile):** Docker, Ubuntu, elan, curl, pip, GNU Make, and system build tools and libraries.

Installation and execution are at your own risk. This project's software is provided "as is", without warranty; external software is subject to its own licenses.
