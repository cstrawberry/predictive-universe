## Inputs and definition of “program”

This is a finite mathematical algorithm, not a claim that its astronomical loops ran. Its input is the tuple (j,c,k,d), integers j>=1,k>=2,d>=1, n=j+8 and exact rational c in[-n,n], with the source's H=8^(-2k), common D=8^d, and the source-bound admissibility/cutoff predicates below. Each loop, entry, error bound and stopping predicate is specified below. This is stronger than asserting that finite-dimensional outputs exist.

C4–C8 below are mathematical instructions, not a claim that a complete root/quadrature interpreter has been executed or implemented. No step returns fixture digits or asks for a supplied matrix oracle. The output digits at actual size are not evaluated here. A mathematical total-program specification and executed output digits are different things.

## C6. Finite Hermite Weyl/AW entries with compact quadrature

For one oscillator use

  psi_r(x)=(Omega/pi)^(1/4) H_r(sqrt(Omega)x)
            exp(-Omega x^2/2)/sqrt(2^r r!).

  W_nm(q,p)=Omega/(2pi) integral exp(-i Omega p y)
                 psi_n(q+y/2) conjugate(psi_m(q-y/2)) dy.

There is NO unevaluated infinite quadrature in this definition: expand the two Hermite polynomials in y and replace each y^a Gaussian transform by

  (i/Omega)^a partial_p^a [sqrt(4pi/Omega) exp(-Omega p^2)].

Thus each kernel is an explicitly generated finite polynomial times exp(-Omega(q^2+p^2)); its constants use factorials, pi and positive square roots only. The four-mode kernel is the product of four such kernels. The identity `<r|OpW(f)|s>=integral f W_sr` fixes all conjugations. The AW kernel is

  A_rs(z)=(Omega/(2pi))^4 exp(-sum|alpha_j|^2)
             product alpha_j^rj conjugate(alpha_j)^sj/sqrt(rj! sj!),
  alpha_j=sqrt(Omega/2)(q_j+i p_j).

The exact dimensionless Hermite/Wigner/AW polynomial numerators use x=sqrt(Omega)q and y=sqrt(Omega)p. Substitute these coordinates, and include sqrt(Omega) for each first-derivative chain factor, before applying the physical-coordinate bounds below. These are the actual four-mode canonical kernels at hbar=1/Omega. They do not use the indexed source's native bath matrices.

The actual matrix entry is the compact eight-dimensional integral

          + A_rs(z) chi(z) (h_new(z)-h_geometry(z) I)_ab] dz.
