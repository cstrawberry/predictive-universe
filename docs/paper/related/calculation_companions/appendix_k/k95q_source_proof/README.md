# Source construction and proofs for Theorem K.9.5q

This folder holds the source construction behind Theorem K.9.5q of Appendix K and its supporting proofs. The companion [k95q-common-source-completion.md](../k95q-common-source-completion.md) summarizes the result.

## Main documents

1. [conjunction/CONJUNCTION_THEOREM.md](conjunction/CONJUNCTION_THEOREM.md): the common source theorem for homogeneous response, capacity and clock.
2. [conjunction/GATE_MAP.md](conjunction/GATE_MAP.md): each requirement of the theorem and where it is proved.
3. [conjunction/COMMON_ERROR_LEDGER.md](conjunction/COMMON_ERROR_LEDGER.md): all errors and resources on the one source.
4. [conjunction/LIMITS.md](conjunction/LIMITS.md): scope and limits.
