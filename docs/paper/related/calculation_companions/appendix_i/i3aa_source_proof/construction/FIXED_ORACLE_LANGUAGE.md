# Fixed paid entry-language interpreter

The declared physical primitive is the finite many-body matrix/CP map specified by its finite entry program. It is not a Python CPU inside the source. This fixed interpreter text, every coefficient program, candidate/parameter code and actual source program is included in the native description book.

Its elementary exact types are integers, rational numbers, finite lists and real/complex rational rectangles. Addition, multiplication, comparisons, Euclidean division and finite loops have their usual explicit digit algorithms. A computable real is a program returning nested rational enclosures at requested width. There is no real-equality instruction.

The norm/spectral/function interpreter consists of these specified algorithms:

1. Rational square roots use scaled integer square-root bisection. Inversion requires a registered positive denominator lower bound and otherwise refines the input enclosure.
2. Exponential uses rational Taylor sums after splitting its argument into pieces of absolute value at most1. Bound the absolute omitted tail by the geometric/factorial tail; negative arguments use reciprocal. Sine/cosine use their rational Taylor series and factorial remainder. Logarithm rescales to [1/2,2], then uses twice the odd-power series in (x−1)/(x+1), with its explicit geometric tail. Pi uses the Machin arctangent identity and alternating-series bounds. These implementations occur in the counted geometry/rational modules.
3. Smooth cutoff eta(x)=0 for x<=0, exp(−1/x) otherwise uses monotonic endpoint bounds. Its kth derivative is exp(−1/x) times an explicitly differentiated polynomial in 1/x. On intervals meeting0, use the maximum of z^m exp(−z) on z>=1/upper_endpoint to enclose each term. This bound tends to0 at the flat join. Bernstein polynomials use de Casteljau/finite differences; Fourier derivatives use the trigonometric routines above.
4. Scalar/profile integrals use rational subdivision and interval Riemann enclosures. Split every explicitly known piecewise join. Refine both input boxes and panel width. A supplied derivative/norm bound can accelerate the error test but is not substituted for actual integral values. A bounded-stage cap returns its valid broad interval, never a false precision certificate.
5. The native oscillator Jacobi spectrum uses exact Hermite-polynomial Sturm sign counts and bisection. Eigenvectors use the Hermite recurrence divided by square-root factorials, then exact finite normalization. The positive first component fixes the basis. No library eigensolver is part of the normative oracle.
6. Finite products, inverses of the explicit positive2x2 F block, tensor contractions, derivatives and sums generate the actual H/source matrices. Full matrix exponentials use the finite Taylor recurrence with exp(||A||)||A||^(L+1)/(L+1)! remainder. Positive-contraction square roots use the binomial series and tail binom(2L,L)/4^L. No discontinuous spectral-bin decision is needed.
7. Finite-U history certification uses these actual matrices, the explicit norm/time-mesh bounds and the registered strict acceptance margins. Common-row search is dovetailed by geometry and precision stages. Invalid/padded physical labels have the explicit idle/reject extension already registered.

Python NumPy/SciPy routines are independent reduced diagnostics, not an unpriced physical runtime. The multiprecision interval adapter in the canonical diagnostic source accelerates elementary interval evaluation; its mathematical entry-language semantics are exactly the rational algorithms above. A physical implementation that instead embeds a particular external software interpreter must pay that separate complete runtime. This construction uses the fixed mathematical entry language declared for literal finite interactions.
